## 📖 ทำความรู้จัก PakMaii (ใน 1 นาที)

**PakMaii (Ready to Grow)** คือผู้ช่วยดิจิทัลที่พัฒนาขึ้นมาเพื่อ **กลุ่มเกษตรกรตำบลผักไหม จ.ศรีสะเกษ** และเจ้าหน้าที่ตรวจรับรองมาตรฐาน (ICS - Internal Control System) เพื่อแก้ปัญหาใหญ่ 3 เรื่อง:

1. **เกษตรกรจดบันทึกไม่เก่ง:** เดิมต้องใช้สมุดจดบันทึกแปลงปลูก ทำให้ข้อมูลสูญหายหรือตกหล่น → **เปลี่ยนมาเป็นกดปุ่มลัดใน LINE หรือกดไมค์พูดภาษาไทยได้เลย**
2. **ขาดน้ำและเสี่ยงแล้งนอกฤดู:** ติดตามสถานะแหล่งน้ำและเชื่อมต่อข้อมูลกับ **"ธนาคารน้ำใต้ดิน / สูบน้ำพลังงานแสงอาทิตย์"** เพื่อให้มีน้ำปลูกถั่วเหลืองอินทรีย์หลังเก็บเกี่ยวข้าว
3. **ข้าวอินทรีย์ขายไม่ได้ราคาเพราะขาด Story:** ผู้บริโภคไม่รู้ว่าข้าวนี้ปลูกด้วยความประณีตอย่างไร → **สร้าง QR Code "Story Passport"** สแกนปุ๊บรู้ทันทีว่าใช้แหนแดงบำรุงดิน ไม่ใช้สารเคมี 100%

```
[ เกษตรกรตำบลผักไหม ] ──( แตะปุ่มใน LINE / กดพูด )──► [ ตรวจสอบมาตรฐานโดย ICS ]
                                                                │
[ ผู้บริโภคประทับใจ ] ◄──( สแกน QR Story Passport )─────────────┘
```

## 🏆 3 เสาหลักนวัตกรรม (The 3 Competition Pillars)

| เสาหลัก | นวัตกรรมที่พัฒนาขึ้น | ประโยชน์ต่อเกษตรกรและชุมชน |
|---|---|---|
| **1. Identity**<br>*(การควบคุมภายใน & ตรวจสอบย้อนกลับ)* | **ระบบคัดกรองความเสี่ยง (ICS Risk Watch-list)** ตรวจจับแปลงที่ขาดการดูแล หรือประวัติไม่สอดคล้องอัตโนมัติ พร้อมออก **QR Story Passport** ล็อตผลผลิต `L-12` | ข้าวหอมมะลิและถั่วเหลืองมีใบรับรองความโปร่งใส ขายได้ราคาสูงขึ้น ผู้บริโภคเชื่อมั่น 100% |
| **2. Security**<br>*(ความมั่นคงด้านแหล่งน้ำ)* | **ระบบติดตามแหล่งน้ำแปลงปลูก (Water Security Monitor)** แยกแปลงที่มีความเสี่ยงขาดน้ำ เพื่อประสานงานสูบน้ำโซลาร์เซลล์ / ธนาคารน้ำใต้ดิน | เกษตรกรมีน้ำเพาะปลูกตลอดทั้งปี ลดความเสี่ยงผลผลิตเสียหายจากภัยแล้ง |
| **3. Community Resilience**<br>*(ปรับเปลี่ยน 3 ปีสู่เกษตรอินทรีย์)* | **ระบบพี่เลี้ยงติดตามระยะปรับเปลี่ยน 3 ปี (3-Year Conversion)** สนับสนุนวงจรเกษตรประณีต: *ข้าวหอมมะลิ ➔ ถั่วเหลืองหลังนา ➔ แหนแดง ➔ ปอเทือง* | ดินดีขึ้น ลดต้นทุนปุ๋ยเคมี สร้างรายได้หมุนเวียนต่อเนื่องทั้งปีอย่างยั่งยืน |

## ✨ ฟังก์ชันเด่นที่ใช้งานง่ายสำหรับทุกคน

### 👨‍🌾 1. ฝั่งเกษตรกร (Farmer Experience — ใช้งานผ่าน LINE OA)
- **🎙️ บันทึกกิจกรรมด้วยเสียง (Voice-to-Text):** อยู่กลางแปลง นิ้วเปื้อนดิน แดดจ้า ก็แค่กดปุ่มไมโครโฟนแล้วพูดภาษาไทย เช่น *"ฉีดพ่นน้ำหมักชีวภาพสะเดา 20 ลิตร"* ระบบจะพิมพ์ข้อความให้อัตโนมัติ
- **🌾 6 ปุ่มลัดรอบเกษตรประณีต:** แตะครั้งเดียวบันทึกทันที (`ปลูกข้าวหอมมะลิ 105`, `ปลูกถั่วเหลืองหลังนา`, `ปล่อยแหนแดง`, `ไถกลบปอเทอง`, `พ่นปุ๋ยหมักอินทรีย์`, `สูบน้ำโซลาร์เซลล์ / ธนาคารน้ำ`)
- **📸 ถ่ายภาพแปลงจริง:** กดถ่ายภาพแปลงผักเพื่อเป็นหลักฐานความโปร่งใส
- **🧪 ขออนุมัติปัจจัยการผลิต:** ยื่นขอตรวจสูตรปุ๋ยหมักทำเอง (เช่น สูตรใบสะเดา + พริก + กากน้ำตาล) เพื่อความถูกต้องตามเกณฑ์อินทรีย์

### 🛡️ 2. ฝั่งเจ้าหน้าที่ตรวจรับรอง (ICS Officer Dashboard)
- **📊 แดชบอร์ดความพร้อมกลุ่ม (Group Readiness 86%):** แสดงสมาชิก 65 ราย, 120 แปลงปลูก, คำขอรอพิจารณา 8 รายการ, และจุดเฝ้าระวัง 12 จุด
- **📋 ตารางเฝ้าระวังพิเศษ (Priority Watch-list ตาม Slide 11):**
  - `A-03`: 🔴 **ขาดการบันทึกกิจกรรม 14 วัน** *(ติดตามด่วน)*
  - `B-01`: 🟠 **มีคำขอปัจจัยการผลิตรออนุมัติ** *(พิจารณาใน 1 คลิก)*
  - `C-12`: 🔴 **ประวัติไม่สอดคล้อง** *(นัดลงตรวจแปลง)*
  - `D-05`: 🟢 **ปกติ** *(ผ่านการรับรอง Certified EU Organic)*
- **✅ อนุมัติปัจจัยการผลิตได้ใน 1 วินาที:** ตรวจสูตรปุ๋ยและให้คำแนะนำแบบเรียลไทม์

### 📱 3. ฝั่งผู้บริโภค (Consumer Experience)
- **📜 QR Code Story Passport (ล็อต `L-12`):** เปิดดูการ์ดเรื่องราวผลผลิต รู้จักเกษตรกรผู้ปลูก ประวัติการใช้แหนแดงบำรุงดิน แหล่งน้ำจากธนาคารน้ำใต้ดิน และผลตรวจรับรองมาตรฐานสากล

## 🛠️ สถาปัตยกรรมทางเทคนิค (For Developers & Technical Reviewers)

โปรเจกต์นี้ถูกออกแบบภายใต้สถาปัตยกรรม **Modern Serverless Edge** ตอบสนองรวดเร็ว ปลอดภัย และมีค่าใช้จ่ายเซิร์ฟเวอร์ต่ำมาก:

- **Runtime:** [Cloudflare Workers](https://workers.cloudflare.com/) (V8 Serverless Edge Engine)
- **Database:** [Cloudflare D1](https://developers.cloudflare.com/d1/) (Serverless SQL Database)
- **Frontend:** Responsive Vanilla Single Page Application (Zero-Build, CSP Level 2 Strict, Touch-first)
- **Mobile Integration:** [LINE Front-end Framework (LIFF)](https://developers.line.biz/en/docs/liff/) & LINE Messaging Webhook
- **Security & Privacy:** มาตรฐาน Zero Trust, RBAC เข้มงวดแยกสิทธิ์เกษตรกรกับเจ้าหน้าที่, ไม่จัดเก็บ Plaintext Token หรือ Credentials

### คำสั่งสำหรับนักพัฒนา:
```bash
# ติดตั้ง dependencies
npm install

# รันชุดทดสอบความปลอดภัยและการทำงาน
npm test

# Deploy อัปเดตโหมด Demo ขึ้น Cloudflare Worker
npm run worker:demo:deploy
```
